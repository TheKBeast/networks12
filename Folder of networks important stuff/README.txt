Diagram tables of database is in Diagram.pdf
SQL script is in Networks SQL.txt (all in next folder whois, it contains all the adding, updating and removal scripts).
Normalisation Example.txt is the example of normalising the entire tables through SQL code.
Table Creation.txt is the full normalised tables without all the stages. (for copy-paste)
One .cs file for all the content. Contains: console code and web code.

COMMAND:
whois cssbct; - dump all content
whois cssbct?location; - one lookup
whois cssbct?location=home; - change location
whois cssbct?location 12?location; - two lookups
whois cssbct?; - delete

HOW TO USE:
Create database, make sure linked to client. Open whois.exe. Then in the folder (net6.0) type CMD into the folder path. Then use from there. Make sure whois is typed first. 
For web texting I used the given HTML test forms.

EXTRA INFORMATION:
UserID is a string, but if you use non numbers it has exceptions due to how I handled it. Forename is spelt Forname as it is in the Spec.
